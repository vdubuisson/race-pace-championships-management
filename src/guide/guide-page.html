How to use this app

If you want to create your own championships from scratch, you can directly go to the "Championships" section.

If you want to import already existing championships, head to the "Import" page.

This page allows you to import championships from various sources:

On this page you can:

  1. Import Race Pace original: This button allows you to import the championships available in the Race Pace application.
  2. Import Blitzer without mods: This button allows you to import the Blitzer's custom championships which does not use any mod.
  3. Import Blitzer with mods: This button allows you to import the Blitzer's custom championships which use mods.
  4. Import custom championships: This section allows you to import your own custom championships. In this section, you can either import your championships' files as CSV files or directly packaged as a ZIP file. In addition to the required championships files, you can also import a drivers.csv file, either as a separate CSV file or included within the ZIP package.

Once you chose your source, you will be led to a 3-step import process to precisely select what you want to import from this source.

In this step, you can choose which championships you want to import from the source.
The table lists every championship available for import, one per row. You can select the championships you want to import by checking the corresponding checkboxes, or simply check the box at the top to select all championships at once. You can also filter the championships by using the filters at the top of the table. In this case, only the championships matching the filter criteria will be displayed and selected for import.
If a championship from the source conflicts with a championship already loaded in your browser, the row in the table will be displayed in yellow. In this case, you can expand the row to see some details of the already loaded championship in red. This can help you choose whether you want to import the new championship or not.

When you are done, you can proceed to the next step.

In this step, you can choose which teams you want to import from the source.
The process is the same as the championship step, where you can select the teams you want to import and see the conflicts with already loaded teams.
The teams participating in the championships you selected in the previous step are automatically selected.

When you are done, you can proceed to the next step.

In this step, you can choose which drivers you want to import from the source.
The process is the same as the previous steps, where you can select the drivers you want to import.

When you are done, you can proceed by clicking the "Import" button at the bottom of the page.

After clicking "Import", you are presented with a confirmation popup to choose the type of import you want to perform.

There are 2 types of import you can choose from:

  • Import with keeping: The championships, teams, and drivers you already have loaded are kept, and the elements you selected for import are loaded alongside them. If you selected conflicting elements, they will replace the existing ones.
  • Import with overwrite: The championships, teams, and drivers you already have loaded are deleted and fully replaced with the elements you selected for import.

Choose the import type that best suits your needs and confirm the action to proceed with the import process.

To view, create, edit or delete championships, head to the "Championships" page.

This page displays a list of all championships currently loaded, one by row. Each row provides key information about the championship, such as its name, car categories and tags.

You can sort the championships by clicking on the column headers, and you can use the filters to narrow down the list based on specific criteria.

On each championship row, you will find action buttons that allow you to view details, edit, or delete the championship.

At the top right, you can click on the "New Championship" button to go to the championship creation page.

This page displays the details of a specific championship, organized in tabs showing its global information, events, cars, invitational cars, and drivers.

At the top right, you will find action buttons that allow you to edit or delete the championship.

This tab shows the global information of the championship. You can see its tags, its introduction text, its scoring system, its car categories, its start/end years, and other info like its prestige and events count.

This tab shows the events of the championship.

At the top, you can see the total count of available events vs the events count of a championship season, and the counts of mandatory and optional events.

On each event card, you can see the event's name, status ( mandatory or optional), track, date, duration, start time and if it's an invitational event.

This tab shows the cars which race during the whole season of the championship for a specific team.

The list is organized by car category, with each category showing the cars count within it versus the total cars count of the championship.

On each car card, you can see the car's livery name, car's model name (if not part of the livery name) and the team assigned to the car.

This tab is the same as the Cars tab except it shows the cars which race only during invitational events.

The list is organized by car category, with each category showing the cars count within it versus the total invitational cars count of the championship.

On each car card, you can see the car's livery name and the car's model name (if not part of the livery name).

This tab shows the custom drivers having a contract for this championship, organized by car category.

On each driver card, you can see the driver's name, its contract end year and the team he's working for.

The creation/editing of a championship is divided into several steps, each corresponding to a specific aspect of the championship.

At each step, you need to fill the required information before proceeding to the next step.

At any time, you can use the "Save as draft" button at the bottom of the page to save the current state of the championship, even if it is incomplete. When doing so, the championship will be saved with a "Draft" tag, and you can continue editing it later.

In this step, you provide the general information about the championship, such as its name, car categories, and other global details.

On some fields, you may find a tooltip to help you understand what it means.

In this step, you create the events for the championship.

At the top, you can see the total count of created events vs the events count of a championship season.

Each event is represented by a card which is the same as the one used for displaying events in the championship details.

You can add a new event by clicking the "Add event" at the top right, and you can edit or delete an event by hovering on its card and clicking the corresponding button.

When creating/editing an event, a form will open on the right of the screen:

In this form, you provide the event details such as its track and its name. When defining the event type, you can select from the following options:

  • time: A time-based event with a duration in minutes (if more than an hour, the duration is displayed in hours and minutes at the bottom).
  • laps: A lap-based event with a set number of laps.
  • distance (miles): A lap-based event with a set distance in miles. When saving the event, the app will convert the distance into laps based on the track length.
  • distance (km): A lap-based event with a set distance in kilometers. When saving the event, the app will convert the distance into laps based on the track length.

In this step, you create the cars which race during the whole season of the championship for a specific team.

At the top of the tab, you can see the current count of created cars versus the maximum grid size allowed based on the tracks used in the championship.

The list is organized by car category, with each category showing the cars count within it versus the total cars count of the championship. The categories displayed are the ones defined in the Global step of the form.

Each car is represented by a card which is the same as the one used for displaying events in the championship details.

You can add a new car in a category by clicking the "Add car" at the top right of the category, and you can edit or delete a car by hovering on its card and clicking the corresponding button.

When creating/editing a car, a form will open on the right of the screen:

In this form, you select the car livery and the team it belongs to. When choosing the team, you can see the number of cars already assigned to each team in this championship.

In this step, you create the cars which race only during invitational events.

The step is similar to the one for creating regular cars except that these cars are not assigned to any specific team.

To view, create, edit or delete teams, head to the "Teams" page.

This page displays a list of all teams currently loaded, one by row. Each row provides key information about the team, such as its name, the number of championships it participates in and the tags of these championships.

You can sort the teams by clicking on the column headers, and you can use the filters to narrow down the list based on specific criteria.

On each team row, you will find action buttons that allow you to view details, edit, or delete the team.

At the top right, you can click on the "New Team" button to go to the team creation page.

This page displays the details of a specific team, organized in tabs showing its global information, cars and drivers.

At the top right, you will find action buttons that allow you to edit or delete the team.

This tab shows the global information of the team. You can see its principal name, its stats like driver loyalty and expectation level, and some championship-related stats.

This tab shows the cars assigned to this team accross your championships.

You can view the list organized by championship, or by car category.

On each car card, you can see the car's livery name, car's model name (if not part of the livery name) and the car category or championship it belongs to based on the current view.

This tab shows the custom drivers having a contract for this team.

You can view the list organized by championship, or by car category.

On each driver card, you can see the driver's name, its contract end year and the car category or championship he races in based on the current view.

The team form allows you to create or edit a team's details, such as its name, principal name and stats.

On some fields, you may find a tooltip to help you understand what it means.

To view, create, edit or delete drivers, head to the "Drivers" page.

This page displays a list of all drivers currently loaded, one by row. Each row provides key information about the driver, such as its name, its championship and its team.

You can sort the drivers by clicking on the column headers, and you can use the filters to narrow down the list based on specific criteria.

On each driver row, you will find action buttons that allow you to view details, edit, or delete the driver.

At the top right, you can click on the "New Driver" button to go to the driver creation page.

This page displays the details of a specific driver. You can see its identity, its contract and its racing skills.

At the top right, you will find action buttons that allow you to edit or delete the driver.

The driver form allows you to create or edit a driver's details, such as its name, championship, team and skills.

The Identity section contains the driver's personal information, such as its name, date of birth, team loyalty and initial ELO.
To edit the ELO, you can either enter a manual value in the field, or click an ELO level letter to generate a random ELO value based on that level.

The Contract section contains information about the driver's current contract, including the championship, car category and team.

The Skills section contains the driver's racing skills, such as Race skill, Aggression, and Consistency.
To edit these skills, you can either enter manual values in the corresponding fields, or click on a skill level to generate random values based on that level.

On some fields, you may find a tooltip to help you understand what it means.

To import custom liveries, head to the "Custom liveries" page.

On the "Custom liveries" page, you can import custom liveries to use them in the championships.

To import custom liveries, simply select your liveries ZIP files from the Import section, or drag and drop them into the designated area. Then click the Import button to complete the process.

Under the Import section, you can see the list of currently loaded custom liveries.

After importing custom liveries, you can select them in the championship form when choosing the car liveries racing in the championship (see the "Cars" section of the "Championship creation/editing" guide).

If a custom livery is no longer needed, you can remove it from the list by clicking the delete button next to the livery.

Keep in mind that when importing custom liveries, they will NOT automatically replace the matching liveries in your championships. You will need to manually select the custom liveries for each car by editing the championship.
Likewise, removing a custom livery from the list will not automatically update the championships that are using it. You will need to manually change the liveries for each affected car.

The export page allows you to export your championships for use in Race Pace.

The Configuration section allows you to choose some settings of the export:

  • File name: Specify the name of the export file.
  • With drivers: Choose whether to include your custom drivers in the export.
  • With track mods: Choose whether to include the available track mods in the export. If not, the export will only contains the base game tracks.

The Championships section allows you to select which championships you want to include in the export.
The table lists every championship available for export, one per row. The championships marked as Draft are not available for export. You can select the championships you want to export by checking the corresponding checkboxes, or simply check the box at the top to select all championships at once. You can also filter the championships by using the filters at the top of the table. In this case, only the championships matching the filter criteria will be displayed and selected for export.

Once you have selected the championships and configured the export settings, you can click the "Export" button at the top right. The exported file can then be used in Race Pace as a blueprint in the "Create your own" section.

This application supports some of the modded content available for Automobilista 2.

If the modded content you are looking for is not available in this application, you will have to add it manually to your custom championships CSV files. You can find a tutorial on how to do this here.

If a car mod is using a modded category, this category can be selected among the available categories when creating or editing a championship. The modded categories are marked with a .

Modded car can then be added like any other car when selecting the livery of a car in the championship form. The modded liveries are marked with a Mod tag.

When viewing a championship details, the modded cars are marked with a .

When you add a modded car to a championship, a Car mods tag will automatically be added to the championship's tags.

Modded tracks can be added like any other track when selecting the track of an event in the championship form. The modded tracks are marked with a Mod tag.

When viewing a championship details, the modded tracks are marked with a .

When you add a modded track to a championship, a Track mods tag will automatically be added to the championship's tags.
