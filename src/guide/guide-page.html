How to use this app

If you want to create your own championships from scratch, you can directly go to the "Championships" section.

If you want to import already existing championships, head to the "Import" page.

This page allows you to import championships from various sources:

On this page you can:

  1. Import Race Pace original: This button allows you to import the championships available in the Race Pace application.
  2. Import Blitzer without mods: This button allows you to import the Blitzer's custom championships which does not use any mod.
  3. Import Blitzer with mods: This button allows you to import the Blitzer's custom championships which use mods.
  4. Import custom championships: This section allows you to import your own custom championships. In this section, you can either import your championships' files as CSV files or directly packaged as a ZIP file. In addition to the required championships files, you can also import a drivers.csv file, either as a separate CSV file or included within the ZIP package.

Once you chose your source, you will be led to a 3-step import process to precisely select what you want to import from this source.

In this step, you can choose which championships you want to import from the source.
The table lists every championship available for import, one per row. You can select the championships you want to import by checking the corresponding checkboxes, or simply check the box at the top to select all championships at once. You can also filter the championships by using the filters at the top of the table. In this case, only the championships matching the filter criteria will be displayed and selected for import.
If a championship from the source conflicts with a championship already loaded in your browser, the row in the table will be displayed in yellow. In this case, you can expand the row to see some details of the already loaded championship in red. This can help you choose whether you want to import the new championship or not.

When you are done, you can proceed to the next step.

In this step, you can choose which teams you want to import from the source.
The process is the same as the championship step, where you can select the teams you want to import and see the conflicts with already loaded teams.
The teams participating in the championships you selected in the previous step are automatically selected.

When you are done, you can proceed to the next step.

In this step, you can choose which drivers you want to import from the source.
The process is the same as the previous steps, where you can select the drivers you want to import.

When you are done, you can proceed by clicking the "Import" button at the bottom of the page.

After clicking "Import", you are presented with a confirmation popup to choose the type of import you want to perform.

There are 2 types of import you can choose from:

  • Import with keeping: The championships, teams, and drivers you already have loaded are kept, and the elements you selected for import are loaded alongside them. If you selected conflicting elements, they will replace the existing ones.
  • Import with overwrite: The championships, teams, and drivers you already have loaded are deleted and fully replaced with the elements you selected for import.

Choose the import type that best suits your needs and confirm the action to proceed with the import process.

To view, create, edit or delete championships, head to the "Championships" page.
